# Provenance

This project extracts the L1 projected single-terminal and L2P token/lexer-state equivalence algorithms from GLRMask. It has an independent Git repository and neutral Rust package namespaces. Originating GLRMask baseline commit: `5657d277854d1a3d1bf8ea760bae4d50a7b0167e`. Extraction worktree: `research/equivalence-599515`, final local commit `5ffc9b03328a5180dadee99e27c90e5517733473`. The original GLRMask integration is separate and remains at its own repository.

The code remains distributed under MIT OR Apache-2.0 as inherited. Benchmarks and manuscript are kept in a private research repository while the draft is under review. The public source is an independently branded *extraction*, not a claim that the code was conceived without GLRMask.
